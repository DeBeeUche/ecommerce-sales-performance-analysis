# E-commerce Sales Performance & Customer Behaviour Analysis

## Project Overview
This project analyses historical e-commerce transaction data from the Online Retail II dataset (2009–2011) to understand sales performance, product trends, customer purchasing behaviour, and geographical revenue distribution.

The project demonstrates the use of Microsoft Excel and Power Query to transform raw transaction data into meaningful business insights through an interactive dashboard.

## Project Objectives
- Analyse monthly and annual revenue trends.
- Identify the top 10 products by revenue.
- Identify the top 10 customers by revenue.
- Evaluate revenue performance across countries.
- Build an interactive dashboard for business decision-making.

## Dataset Description
**Dataset:** Online Retail II

The dataset contains e-commerce transaction records with the following fields:
- Invoice
- StockCode
- Description
- Quantity
- InvoiceDate
- Price
- Customer ID
- Country

## Tools & Technologies
- Microsoft Excel
- Power Query
- PivotTables
- PivotCharts
- Excel Data Model
- Interactive Slicers and Timeline

## Data Cleaning & Preparation
The dataset was cleaned and prepared using Power Query.

Key activities included:
- Removed 34,335 duplicate records.
- Corrected data types.
- Created a Revenue column using Quantity × Price.
- Identified missing customer IDs and product descriptions.
- Examined negative quantities and zero or negative prices.

The cleaned dataset contained 1,033,036 records.

## Analysis Performed

### 1. Monthly Sales Analysis
Examined revenue trends across months and years from 2009 to 2011.

### 2. Product Performance Analysis
Identified the top 10 products based on calculated revenue.

### 3. Customer Behaviour Analysis
Identified the top 10 customers based on calculated revenue.

### 4. Country Performance Analysis
Compared calculated revenue across countries to identify major contributing markets.

## Key Findings
- Total calculated revenue was approximately £18.86 million.
- 2010 recorded the highest calculated annual revenue.
- The United Kingdom was the leading country by calculated revenue.
- Product and customer performance varied across the reporting period.
